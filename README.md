# staffpay-live

The **live, hosted** StaffPay app (served free via GitHub Pages).

- This repo = the **open shop** (what you open on your phone).
- The private `staffpay` repo = the **workshop** (where code is built).

**Current:** Shanky's real single-page StaffPay app, published as-is. It stores
data **on each device** (localStorage) for now — the "showroom" version. Next
step: wire it to the shared online brain (Supabase) + logins so it's multi-user.

No secrets in this repo — the app currently holds no keys.
